## 인공 신경망이란?

인공 신경망(Artificial Neural Network)은 인간의 뇌 구조에서 영감을 받은 기계학습 모델입니다.

### 생물학적 뉴런 vs 인공 뉴런

**생물학적 뉴런:**
```
수상돌기 → 세포체 → 축삭돌기 → 시냅스
(입력)   (처리)   (출력)     (전달)
```

**인공 뉴런:**
```
입력(x) → 가중합(Σw·x) → 활성화(f) → 출력(y)
```

### 주요 구성 요소

1. **입력 (Inputs)**: 데이터의 특성들
2. **가중치 (Weights)**: 각 입력의 중요도
3. **편향 (Bias)**: 활성화 임계값 조절
4. **활성화 함수 (Activation Function)**: 비선형성 부여

## 퍼셉트론의 원리

### 단일 퍼셉트론

가장 간단한 형태의 인공 신경망입니다.

**수학적 표현:**
```
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
y = f(z)
```

행렬 표현:
```
y = f(W·X + b)
```

### 퍼셉트론의 학습

**퍼셉트론 학습 규칙:**
```
w_new = w_old + η * (y_true - y_pred) * x
```

여기서:
- `η` (eta): 학습률
- `y_true`: 실제 레이블
- `y_pred`: 예측값
- `x`: 입력값

### 선형 분류의 한계

퍼셉트론은 **선형 분류**만 가능합니다.

**분류 가능:**
- OR 게이트
- AND 게이트
- NOT 게이트

**분류 불가능:**
- XOR 게이트 (비선형 문제)

이것이 바로 다층 신경망이 필요한 이유입니다!

## 다층 신경망

### MLP (Multi-Layer Perceptron)

여러 층의 퍼셉트론을 쌓아 복잡한 패턴을 학습합니다.

**구조:**
```
입력층 → 은닉층1 → 은닉층2 → ... → 출력층
```

### 보편 근사 정리

충분히 많은 은닉 뉴런을 가진 단일 은닉층 신경망은 어떤 연속 함수도 근사할 수 있습니다.

### 층별 역할

1. **입력층**: 데이터 수신
2. **은닉층**: 특징 추출 및 표현 학습
3. **출력층**: 최종 예측

## 역전파 알고리즘

신경망 학습의 핵심 알고리즘입니다.

### 학습 과정

#### 1. 순전파 (Forward Pass)

입력에서 출력으로 계산:

```
Layer 1: a¹ = f(W¹·x + b¹)
Layer 2: a² = f(W²·a¹ + b²)
...
Output: y = f(Wᴸ·aᴸ⁻¹ + bᴸ)
```

#### 2. 손실 계산

예측과 실제값의 차이:

```
L = (1/2)(y - ŷ)²  (MSE)
```

#### 3. 역전파 (Backward Pass)

출력에서 입력으로 기울기 계산:

**출력층:**
```
δᴸ = (aᴸ - y) ⊙ f'(zᴸ)
```

**은닉층:**
```
δˡ = (Wˡ⁺¹ᵀ · δˡ⁺¹) ⊙ f'(zˡ)
```

**기울기:**
```
∂L/∂W = aᵀ · δ
∂L/∂b = δ
```

#### 4. 가중치 업데이트

```
W = W - η * ∂L/∂W
b = b - η * ∂L/∂b
```

### 연쇄 법칙 (Chain Rule)

역전파의 핵심은 미적분의 연쇄 법칙입니다:

```
∂L/∂w = (∂L/∂y) · (∂y/∂z) · (∂z/∂w)
```

## 경사하강법

최적의 가중치를 찾는 최적화 알고리즘입니다.

### 기본 원리

손실 함수의 기울기 반대 방향으로 이동:

```
w_new = w_old - η * ∂L/∂w
```

### 경사하강법의 종류

#### 1. 배치 경사하강법 (Batch GD)

```python
# 전체 데이터로 기울기 계산
gradient = compute_gradient(all_data)
weights -= learning_rate * gradient
```

**장점**: 안정적인 수렴
**단점**: 느린 속도, 많은 메모리

#### 2. 확률적 경사하강법 (SGD)

```python
# 샘플 하나씩 기울기 계산
for sample in data:
    gradient = compute_gradient(sample)
    weights -= learning_rate * gradient
```

**장점**: 빠른 속도, 적은 메모리
**단점**: 불안정한 수렴

#### 3. 미니배치 경사하강법

```python
# 작은 배치로 기울기 계산
for batch in batches:
    gradient = compute_gradient(batch)
    weights -= learning_rate * gradient
```

**장점**: 속도와 안정성의 균형
**단점**: 배치 크기 튜닝 필요

### 학습률 (Learning Rate)

학습률은 매우 중요한 하이퍼파라미터입니다:

- **너무 크면**: 발산 (overshooting)
- **너무 작으면**: 느린 수렴
- **적절하면**: 빠르고 안정적인 수렴

일반적인 값: 0.001 ~ 0.1

## 활성화 함수

신경망에 비선형성을 부여하는 핵심 요소입니다.

### 1. Sigmoid

**수식:**
```
σ(x) = 1 / (1 + e⁻ˣ)
```

**도함수:**
```
σ'(x) = σ(x) · (1 - σ(x))
```

**특징:**
- 범위: (0, 1)
- 확률 해석 가능
- 기울기 소실 문제

**용도:** 이진 분류 출력층

### 2. ReLU (Rectified Linear Unit)

**수식:**
```
f(x) = max(0, x)
```

**도함수:**
```
f'(x) = { 1 if x > 0
        { 0 if x ≤ 0
```

**특징:**
- 범위: [0, ∞)
- 계산 효율적
- 기울기 소실 완화
- Dead ReLU 문제

**용도:** 은닉층 (가장 널리 사용)

### 3. Tanh

**수식:**
```
tanh(x) = (eˣ - e⁻ˣ) / (eˣ + e⁻ˣ)
```

**도함수:**
```
tanh'(x) = 1 - tanh²(x)
```

**특징:**
- 범위: (-1, 1)
- Zero-centered
- Sigmoid보다 강한 기울기

**용도:** 은닉층

### 4. Softmax

**수식:**
```
softmax(xᵢ) = eˣⁱ / Σⱼ eˣʲ
```

**특징:**
- 출력의 합이 1
- 확률 분포로 해석

**용도:** 다중 클래스 분류 출력층

### 활성화 함수가 필요한 이유

활성화 함수가 없으면:
```
y = W₂(W₁x + b₁) + b₂
  = (W₂W₁)x + (W₂b₁ + b₂)
  = W'x + b'
```

결국 선형 변환이 되어 층을 쌓는 의미가 없습니다!

## 손실 함수

모델의 성능을 측정하는 함수입니다.

### 1. 평균 제곱 오차 (MSE)

**수식:**
```
L = (1/n) Σᵢ (yᵢ - ŷᵢ)²
```

**용도:** 회귀 문제

**특징:**
- 이상치에 민감
- 미분 가능
- 기울기가 오차에 비례

### 2. 이진 크로스 엔트로피

**수식:**
```
L = -(1/n) Σᵢ [yᵢ log(ŷᵢ) + (1-yᵢ) log(1-ŷᵢ)]
```

**용도:** 이진 분류

**특징:**
- 확률적 해석
- Sigmoid + BCE 조합 효과적

### 3. 범주형 크로스 엔트로피

**수식:**
```
L = -(1/n) Σᵢ Σⱼ yᵢⱼ log(ŷᵢⱼ)
```

**용도:** 다중 클래스 분류

**특징:**
- Softmax + CCE 조합 효과적
- 원-핫 인코딩 필요

## 학습 팁

### 1. 가중치 초기화

**Xavier/Glorot 초기화:**
```python
W ~ Uniform(-√(6/(n_in + n_out)), √(6/(n_in + n_out)))
```

**He 초기화 (ReLU용):**
```python
W ~ Normal(0, √(2/n_in))
```

### 2. 정규화

**L2 정규화:**
```
L_total = L_data + λ * Σ w²
```

**드롭아웃:**
학습 중 일부 뉴런을 무작위로 비활성화

### 3. 배치 정규화

각 층의 입력을 정규화하여 학습 안정화

### 4. 조기 종료

검증 손실이 증가하면 학습 중단
